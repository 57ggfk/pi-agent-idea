实现笔记（FR-006 实测结论）：

- **diff = 原生支持**：`highlight.js/lib/common` 实测含 diff 语法（`hljs.highlight(code, {language:'diff'})` 输出
  `hljs-addition/hljs-deletion/hljs-meta/comment`）。零新依赖，只加三条 CSS token 配色（主题变量）。
- **脚注 = 新增实现**：marked 15.0.12 实测不支持 GFM 脚注（`[^1]` 原样输出）；新增 `marked-footnote` 1.4.0
  （peer marked>=7，零运行时依赖，2025-07 仍在维护）。
- 安全联动：DOMPurify hook 原来给所有 `<a>` 加 `target=_blank`，脚注锚点 `href="#..."` 必须豁免——否则 IDE 宿主
  里点脚注会弹第二个窗口（且与 037 的 popup 拦截相互作用）。
- 真机 JCEF 未跑（无真机会话）；渲染管线与 e2e 走的是同一 Chromium。
