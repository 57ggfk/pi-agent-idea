| 套件 | 结果 | 基线变化 |

**实现要点**：`autosizeAndReveal` = autosize + 同帧 `scrollTop=scrollHeight`；收口 effect 等待
「已提交 value 长度 === 期望长度」再测量（updater 里捕获期望值，effect 体同步种下 `-1` 哨兵）——
这一步修掉了**实测复现的根因级竞态**：React 18 并发渲染会把 quote 的 updater 推迟到首个 rAF
**之后**执行，settle 读到旧值（12 字符 / 38px）且 `expected` 还是 null，直接按过期值收口，之后
再无重测——这正是用户「时好时坏」的完整机理（探针证据：`note len=168` 出现在 `settle` 日志之后）。
可疑测量判据放宽为「`style.height < clampComposerHeight(scrollHeight, appHeight) - 1`」（覆盖 38px
这类非 floor 的过期值与 0 高度布局两种形态）；`.app` ResizeObserver 恢复时一次性
autosizeAndReveal 并清标记；普通重测（字体加载、窗口缩放）保持裸 autosize，绝不滚动（US4）。
e2e 备忘：playwright 的 loader 不接受 `import("@playwright/test").Page` 内联类型导入（用顶层
`import type { Page }`）；消息工具条 hover 才可见（`visibility:hidden`），断言前先 hover。
