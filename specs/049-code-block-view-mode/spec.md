# Feature Specification: 代码块「渲染 ⇄ 源码」模式切换（换行只在源码模式生效）

**Feature Branch**: `release/0.5.10`

**Created**: 2026-11-20

**Status**: Implemented（已实现；发布文案见 changelog.d/049-*）

**Input**: 用户提出（2026-11-20，内测第三轮）
> 现状描述：代码块 svg mmd 等默认是渲染模式。期望增加切换为代码默认，两种模式切换，只有代码默认换行切换才有效。

## 一、意图与边界

用户指出：**```svg / ```mermaid 这类默认渲染成图的代码块，只能看图、看不到源码**，
且 048 加的「换行」开关在这种块上**没有意义**（图里没有「行」可换）。要求：

1. 给默认渲染成图的代码块加一个**模式切换**：渲染 ⇄ 源码，两种模式来回切。
2. **换行开关只在源码模式下生效**（渲染模式下无效）。

本规格锁定四条边界：

- **默认仍是渲染模式**。用户说的是「增加切换为代码」的能力，不是把默认改掉。
- **只有「默认渲染成图」的块才有模式开关**（```svg / ```mermaid）。普通代码块
  本来就是源码，没有第二个模式可切 —— 不给它加一个永远没用的按钮。
- **不新增 IDE 桥接、不新增依赖**。纯前端呈现，沿用 048 的标题栏与既有按钮。
- **不动其它 Markdown 行为**：表格、脚注、diff 高亮、KaTeX、行内图形全部零回归。

## 二、可行性与现状（读码核实 + 实测）

- **切换按钮放标题栏**：048 的标题栏右侧已经有复制 / 在 IDE 打开 / 换行 / 复制为图片，
  模式开关是同一类控件，加进去即可（`.code-source-btn`）。
- **状态必须存模块级**（同 048 的换行状态）：`message_end` 会用权威消息整条替换
  assistant item（新的 item id → React 重挂载 → `useRef` 归零）。键取
  **「语言 + 块序号 + 源码开头」**（`blockStateKey`）。
- **键里为什么要有块序号**（实测踩坑）：源码前缀回溯的前提是「早先的键是当前键的
  前缀」。若键里只有语言与源码，源码还空着的块（键 = `mermaid:`）会匹配到消息里
  **每一个** mermaid 块 → 用户在一个块上的选择会跑到别的块上。加上块序号后，
  只有同一个块（同样语言 + 同样序号）才可能互为前缀。
- **键里必须去掉 marked 补的结尾换行**（实测踩坑）：marked 给围栏内容补了一个结尾
  `\n`，于是渲染出的源码是「原始源码 + 一个换行」。流式中途的两段源码因此**不再成
  前缀**（`"graph TD;\n  \n"` vs `"graph TD;\n  A[Start] \n"`）→ 前缀回溯认不出
  同一个块，用户在流式中途做的选择会丢。键统一去掉那一个结尾换行。
- **状态要「跟着源码往前带」**：键随源码变长，早先的键只能靠前缀回溯认出来；认出来
  之后顺手记到**当前**键上（`carryForwardState`），下一次就不用再靠回溯。只有
  「非默认」的状态才带（默认的渲染 / 不换行不写），免得盖掉用户更晚的选择。
- **换行开关的可用性跟着「代码是不是真的显示着」走**：源码在屏幕上 → 换行可用；
  代码被图形顶掉 → 换行禁用（`disabled` + 变灰）。这不是「两种模式」的附属品，
  而是「屏幕上有没有行可换」的事实。
- **图形必须记住自己是从哪份源码画出来的**（实测踩坑）：流式期间同一个块会被反复
  重建，同一份源码可能同时有多个渲染请求在飞，而 `renderMermaid` 的并发保护会让
  后来的请求直接返回 `null`。`null` 只说明「这次没画成」，**不代表屏幕上那张图是
  错的** —— 049 之前没有这个标记，后来的 `null` 请求会把刚画好的图拆掉，块永远停在
  源码上（048 的 mermaid 图形一度渲染不出来，根因在此）。现在图形带
  `data-mermaid-marker`，只有当它属于**另一份**源码时才会被撤掉。

## 三、User Scenarios & Testing

### US1 - 图和源码来回切 (P1)
```svg / ```mermaid 块默认出图。用户点标题栏里的「源码」→ 图形收起、源码显示；再点
→ 图形回来、源码隐藏。源码模式下一行行号也在（源码在屏幕上才有行号）。

### US2 - 换行只在源码模式有效 (P1)
渲染模式下「换行」按钮是灰的、点不动（图里没有行可换）；切到源码模式它就能用了，
长行折行显示；切回渲染模式又变灰，但用户之前选的换行状态被记住。

### US3 - 渲染不出来的块 (P1)
语法错的 Mermaid、画不出的 SVG：块显示源码（降级），切到「渲染」时按钮闪 ✗ 并
留在源码 —— 不给用户一个点了没反应的按钮。

### US4 - 源码模式锁得住 (P1)
流式输出还没写完时（源码还不合法、渲染不出来），用户点「源码」把模式锁定；等源码
写完、可以渲染了，这个块**仍然**显示源码。

## 四、Requirements

- **FR-001** 默认渲染成图的代码块（```svg / ```mermaid）MUST 在标题栏里有一个模式
  开关；MUST 默认处于渲染模式；MUST 能在渲染 ⇄ 源码之间来回切；普通代码块 MUST NOT
  出现该开关。
- **FR-002** 模式开关 MUST 显示当前意图（`aria-pressed=true` ⇔ 源码模式已锁定），
  MUST 永不禁用 —— 切到源码必须永远可用。
- **FR-003** 换行开关 MUST 只在**源码显示着**时可用（渲染模式 → `disabled` 且视觉
  变灰）；MUST NOT 改动按钮的字号、边框、间距、底色（048 的「所有块按钮同一套外观」
  依赖这一点）；用户先前的换行选择 MUST 被记住。
- **FR-004** 模式 MUST 存在模块级状态表（组件会被 `message_end` 重挂载），键 =
  语言 + 块序号 + 源码开头；MUST 在流式重建 / 组件重挂载后仍然保持；MUST NOT 串到
  别的块上。
- **FR-005** 渲染不出来时 MUST 降级显示源码；切到渲染 MUST 有可见反馈（闪 ✗），
  MUST NOT 静默无响应；MUST NOT 改写用户的模式意图（流式中源码还没写完时渲染失败是
  常态，源码合法了自然出图）。
- **FR-006** 图形 MUST 记住自己来自哪份源码；MUST NOT 被「同一份源码的另一次并发
  渲染请求返回 null」误拆；只有属于**另一份**源码的图形才允许被撤掉。
- **FR-007** 本增强 MUST NOT 回归：Markdown 其它语法（表格、脚注、diff 高亮、KaTeX）、
  041「在 IDE 打开」、047「复制为图片」、040 Mermaid 主题、008 双语。
- **FR-008** 模式开关 MUST 随面板主题一致（深色下面板不得出现浅色块）；禁用态 MUST
  只用颜色与透明度表达。

## 五、Decisions（2026-11-20）

| # | 问题 | 结论 |
|---|---|---|
| Q1 | 默认是渲染还是源码 | **渲染**（用户原话「代码块 svg mmd 等默认是渲染模式」是现状描述，「增加切换」是要加能力） |
| Q2 | 按钮文案怎么写 | 固定「源码」，`aria-pressed` 表示「源码模式已锁定」——与 048 的「换行」开关同构（文案是状态名，aria-pressed 是该状态是否开启） |
| Q3 | 渲染不出来的块，开关置灰还是闪 ✗ | **闪 ✗**：置灰会让「切到源码」这个最该可用的方向也点不动（流式中源码常常渲染不出来，置灰等于不让用户看源码） |
| Q4 | 状态键怎么取 | 语言 + **块序号** + 源码开头；键里去掉 marked 补的结尾换行（否则前缀关系断掉） |
| Q5 | 换行开关的可用性按什么判 | 按「代码是不是真的显示着」：源码在屏幕上 → 可用；被图形顶掉 → 禁用。这比「按模式判」更诚实（降级块显示的就是源码，它的换行当然该能用） |

## 六、不做的事

- 不做「渲染 / 源码」两个并列按钮（标题栏挤不下，也不如一个状态开关清楚）。
- 不给普通代码块加模式开关（没有第二个模式）。
- 不做「按语言记住模式偏好」的全局设置（只做按块）。
- 不新增 IDE 桥接方法、不新增 npm 依赖。
- 不做源码编辑（源码仍是只读的代码块，复制 / 在 IDE 打开照旧）。

## 七、与既有规格的关系

- **048（代码块标题栏 / 换行 / 行号 / svg 围栏渲染）**：本规格**收窄**其 FR-003 ——
  换行开关仍然默认关闭、仍然按块生效，但**只在源码模式生效**（048 追加章节已记）。
  048 的行号槽（源码隐藏时收起）在源码模式下自动恢复，无需改动。
- **040（Mermaid）**：Mermaid 的渲染路径提到模块级（`renderMermaidBlock`）以便模式切换
  复用；渲染语义、主题、错误降级不变，只补了「图形记住自己来自哪份源码」这一条
  （FR-006，顺手修掉一个会让图形永远渲染不出来的老账）。
- **047（复制为图片）**：源码模式下图形不在了 → 「复制为图片」入口随之撤掉；切回渲染
  模式重新出现。降级块依然没有该入口（FR-007 不变）。
