## 3. 实现要点与踩坑（可复用）

1. **模型选择器**（T004–T013）：`buildPickerData` 纯函数 + `ensureVisible`（读一次几何、只写 `.model-list.scrollTop`）；outside-click 照抄 OptionsPopover，rootRef 包住 chip。e2e 教训：弹窗向上展开会盖住 composer 左半，Playwright 拒点被覆盖元素——点输入框右端；CSS `text-transform` 会改 `innerText`，断言要小写化。
2. **skill 折叠**（T014–T018）：单点转换 = `itemToMarkdownSource`（Copy/Quote/Edit 全走它）+ 渲染层 `displayBlocks`；**乐观回显（raw 命令）与 message_end（展开文）去重必须按 display 形态比较，且 display 等价但 raw 不同时要替换为 pi 的权威文本**——否则数据层丢原文、搜索搜不到正文（这是实现中发现修掉的真 bug）。
3. **CLI 解码**（T019–T023）：`drainThread` 改字节读 + `decodeOutput`（回退 charset 可注入，Windows 场景 macOS 可测）；`CliText.sanitize/safeTruncate` 一条管道；`PiManage.cliOutput` 统一两处 `take(2000)`。`\b` 语义用 pop 模型。
4. **会话标题**（T105–T109）：事件驱动同步 sessions 数组（0 次额外请求）；`manualTitle` 挡后续事件；`SessionTitleInput` 单编辑器（状态栏 / 当前行按 tab 分置，永不双输入框）。mock 的 `sessionId` 对齐到 `mockSessions[0].id` 是前置修复。
5. **Tooltip**（T110–T114）：全局委托 `[data-tip]`，零组件侵入；**hide 用 `hidden` 属性而非 opacity**（Playwright 视 opacity:0 为可见）；pointerdown 后 800ms 抑制同元素重显（focusin 会立刻拉起）；z-index 30 < 确认框 40。
6. **AGENTS.md**（T115–T120）：`PiAgents` 复刻 pi 加载算法；路径白名单（global + project）防任意文件打开；create 幂等 + UTF-8。平台 API：`FileSaverFactory` 不存在，正确的是 `FileChooserFactory.getInstance().createSaveFileDialog`；`VirtualFileWrapper.getFile()`。
7. **安装独占**（T121–T126）：门控上提 store（`setupGate`），App 提前 return 只渲染引导子树；`setTab` 门控期 no-op；检测失败**永不锁 UI**（error 态 = 主界面 + 横幅 + 重试）。mock 需要 `setupInstalled` 状态机让「装完 re-detect」能解除门控。e2e 教训：`abort-btn` 消失才代表 settle（send-btn 在 queue 模式下常显）；abort=false 有歧义（optimistic 与 agent_start 之间的窗口），必须「先见 busy 再见 idle」。
8. **provider 链路**（T127–T133）：`PiCredentials`（锁 + merge + 回读 + 0600）；响应只带 provider 名（测试断言 key 材料零出现）；`ProviderForm` 两处复用；安装成功后 `offerProviderStep` 一次 + `config.setPrefs` 持久化跳过（Q8）。
9. **图片预览**（T134–T140）：Portal + `appliedRef` 门控「从 request 推导 index」——**否则 assistant 流式期间 items 每次变化都会把预览拉回第一张并重置缩放**（实现中发现）；`hidden` 属性控制显隐；保存对话框/剪贴板走 `ide.saveImage`/`ide.copyImage`（JCEF 无 async clipboard）。又一个实现期真 bug：mock 模式复制按钮被我留了硬编码失败的占位分支——全量回归抓出后移除。
10. **零泄漏断言**（T133）：e2e 用哨兵 key `SK-E2E-SENTINEL-XYZ` 全页文本 + console 扫描；Kotlin 侧响应断言同样不含 key。
