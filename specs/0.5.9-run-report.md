## 7. D. 真机发现的缺陷与修复

**缺陷 #1 — 关闭任一实例后「+」永久失效、实例号无法复用。**
`NewInstanceAction.update` 用 `PiProcessManager.liveInstanceIds().size() < 4` 判断；关闭实例后残留的 `/bridge/poll` 会经 `ensureWired → wirePiEvents → addEventListener/addStateListener → slot(id)` 把已删除的 slot 重建，计数恒为 4；且 title action 的 `e.getProject()` 不可靠。
修复：`NewInstanceAction` 构造时显式持有 `Project`；`update` 改用 `ContentManager.getContentCount()`；`actionPerformed` 与新增 `nextInstanceId(ToolWindow)` 从**真实 Content 的 panel id** 取最小未占用号。

**缺陷 #2 — 关闭默认实例 1 泄漏 pi 进程与事件桶。**
`CloseGuard.contentRemoved` 的 `if (id != 1)` 与 `BridgeService.closeInstance` 的 `if (instanceId == 1) return` 跳过清理。
修复：移除两处特判，所有实例统一 `stopInstance` + `closeInstance`（避免为兼容门面保留实例 1 而破坏「关标签=结束进程」）。

本轮缺陷修复只触及 C3 既有改动中的以下两个源码文件（未新增源码文件）：

- `src/main/java/dev/pi/agent/toolwindow/PiAgentToolWindowFactory.java`（+ import `HashSet`/`Set`）
- `src/main/kotlin/dev/pi/agent/bridge/BridgeService.kt`

两个文件均为全 CRLF，`Edit` 前后行数与 `\r\n` 计数一致（Java 225/225，Kotlin 1276/1276），未用假定 LF 的脚本替换。修复后重跑 §1 全部命令，全绿。
