**Feature Branch**: `release/0.5.10`

**Created**: 2026-11-18

**Status**: Draft — **042 P0 层的可实施规格**（spec/plan/tasks 三段式齐备）。042 保持方向性记录（P1/P2 不在本版）；[043](../043-browser-protocol-cert/spec.md) 证书策略单独交付，本版只挂默认严格策略与 hook 接口。技术结论全部来自已完成的真机探针（[exploration.md](../042-in-app-browser/exploration.md)、探针报告 v1–v6，见 plan §0）。

**Input**: 用户（2026-11-16 拍板 042 Q1–Q4；2026-11-18「整理 spec/plan/task，开始开发」）
> P0 预览基座：URL 地址栏（展示+可编辑）、前进/后退/刷新、工具窗页签 + 编辑器呈现、打开 localhost / 本地 HTML / 公开 URL、外链默认系统浏览器不变。

## 一、定位（承 042）

给 IDE 一个**可用的内置浏览器页签**：地址栏输入或粘贴 URL，在 IDE 内渲染、导航、前进后退；本地 HTML 文件可一键预览；聊天里的外链按设置路由（默认不变）。它是 042 分层路线（P0 预览基座 → P1 开发交互 → P2 批注回流）的地基层，本版只交付 P0。

## 二、User Stories（用户价值）

### US1 - 地址栏导航 (P1)
用户在浏览器页签地址栏输入或粘贴 URL（自动补 `http://`），回车或点 Go 后页面在 IDE 内加载；地址栏与页面标题随导航实时回显（含页内跳转）。

### US2 - 历史导航 (P1)
用户可后退/前进/刷新；按钮在无可后退/前进历史时置灰。

### US3 - 本地 HTML 预览 (P1)
用户对项目内 HTML 文件右键「在 Pi 浏览器中打开」即可预览；会话导出 HTML 完成后通知里点「预览」直接打开，不用先找到文件再用系统浏览器开。加载不走 `file://`（安全约束，见 §五）。

### US4 - 外链路由设置 (P2)
用户在设置里选择聊天外链去向：**系统浏览器（默认）/ 内置浏览器 / 每次询问**。默认行为与现状完全一致（037 语义不变）；选内置浏览器时点聊天外链在浏览器页签打开；「每次询问」弹一次确认。

### US5 - 弹窗行为可预期 (P1)
页面里 `target=_blank` 链接点击后在**同一页签内导航**到目标——绝不弹独立 Chromium 窗口，也**绝不静默丢弃**（真机教训：静默丢弃 = 「链接都不能跳转」）。

### US6 - 下载可感知 (P2)
页面触发下载时文件落盘到系统下载目录并以通知告知结果；没有 handler 时下载凭空消失的现状（探针实证）不允许再出现。

### US7 - 加载失败与崩溃可见、可恢复 (P1)
页面加载失败（DNS/拒绝/证书拦截）显示明确错误卡（含原因与重载按钮），不是白板；渲染进程死亡自动重建浏览器（带防风暴熔断，超限进常驻错误卡）。

### US8 - 与 Pi 实例页签并存不干扰 (P1)
浏览器页签与 Pi 实例页签（019）共存于同一工具窗：浏览器不占 pi 实例计数与命名、不进事件分桶、无 pi 进程；关闭浏览器页签不需要确认（无生成可中断），不影响任何 pi 实例。

### US9 - 编辑器呈现 (P3，可滑出)
HTML 预览也可在编辑器区以标签页形态打开（042 Q3 双形态的另一半）；两种形态互不共享导航状态（v1 简化）。本任务轨排在最后，允许滑出到下一版。

## 三、验收口径

- US1：粘贴 `example.com` 补全为 `http://example.com` 并加载；页内跳转后地址栏回显新 URL；标题回显与页面 `document.title` 一致。
- US5：真机点击 `target=_blank` 链接 → 屏幕上**不出现**新浏览器窗口，当前页签 URL 变为目标 URL；handler 日志可见拦截+接续记录。
- US6：点击下载链接 → 下载目录出现文件（字节数与响应一致）+ 通知弹出；下载失败有失败通知。
- US7：加载不存在域名 → 错误卡可见（非白板）；真机杀渲染进程 → 自动重建 ≤ 熔断上限，超限后常驻错误卡带手动重载。
- US8：开浏览器页签后：pi 实例页签命名/计数不变、两实例事件不串台（复用 019 单测口径扩展）。
- US4：默认态点击外链 → 系统浏览器打开（现状零变化）；内置态 → 页签打开；询问态 → 一次确认。
- 零回归：`gradlew test`、`vitest`、`playwright` 全量基线不破；`verifyPlugin` 全 Compatible（只用公开 `com.intellij.ui.jcef` / `org.cef` API）。
- i18n：新增用户可见文案中英双字典；无 JCEF 环境（Android Studio 等）下浏览器入口置灰或提示，不崩溃。

## 四、Non-goals（本版不做）

- DevTools / 控制台日志进会话 / 批注回流（042 P1/P2）。
- 证书策略配置 UI 与放宽（**043** 的范围；本版只有默认严格 + hook）。
- 登录态/cookie 隔离：探针实证 CEF 122 `CefRequestContext.createContext` **不隔离 cookie**（全局共享）。口径修正（0.5.10 走查 F-215 M3）：登录态**存储**由平台全局持久 profile 提供（243 起 `jcef_cache` 无条件落盘，本机 2026.2/jcef_cache 实证 28KB Cookies 文件）——表单登录可用且跨 IDE 重启保留；推迟的是**隔离**（分区隔离待 CEF partition API，262 的 `createContext` 仍无 settings 参数）。安全模型仍按「共享」设计，内置浏览器不承载敏感登录态。
- 输入时过滤联想（历史下拉只做最近访问直达，键入过滤需 document listener + JBPopup，二期）、跨 IDE 重启的历史持久化（需持久化面并先做 URL 隐私决策，F-201 修订：会话内地址栏下拉历史提前进 0.5.10）。
- 多标签页保留为 non-goal（F-208 仅 MVP：同一工具窗按 URL 复用/新建 Content，上限 4，不做标签管理 UI）。
- agent 自主浏览（042 P3 仅记方向）。

## 五、硬约束（真机探针实证，实施不得违反）

1. **token 零进入**：内置浏览器实例不加载任何带桥接 token 的 URL；与 `BridgeService`/`LocalUiServer` 桥接面零关联（P0 零 JSQuery 注入）。
2. **file:// 不走主加载路径**（⚠ 2026-11-21 已按用户授权放宽，见修订注记）：本地 HTML 一律经一次性只读预览路由或等价受控通道。
   > **修订（2026-11-21，054 批）**：用户授权放宽——项目内本地 HTML 经「Open in Pi Browser/Editor」右键直接以 `file:///` 真实路径打开（地址栏显示真实路径，无 token 时效问题），仅限用户主动右键打开的本地文件；聊天导出预览仍走一次性 token 路线。硬约束 1（token 零进入）不变。实现与验收见 run-report「054 打开形态批」段。
3. **弹窗禁止静默丢弃**：拦截即接续（同视口导航）。
4. **下载必须显式 handler**：CEF 原生路径（反斜杠）；正斜杠路径会静默滞留（探针实证）。
5. **单一 windowed 实例**：同一工具窗内只建一个 windowed 原生浏览器（HWND 会错位压住 Swing 组件，多原生实例加剧）；其余形态用 OSR。
6. **崩溃判定不用 `JBCefHealthMonitor`**（2024.3 不存在该类，探针实证）：用 `onRenderProcessTerminated` + `onLoadError`。
7. **旧帧残留治理**：导航后沿用 `wasResized` 强制重绘（仓库 0.5.4 已验证的 workaround）。
8. **日志卫生**：浏览 URL（含 query）与页面 console 不以明文进 idea.log。
