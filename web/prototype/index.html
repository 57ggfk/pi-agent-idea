看了下 web/src/styles.css 和几个组件，问题主要不是配色，而是缺少统一的设计 token 和图标体系。

先确认样式规模，再定位重复定义和响应式断点。 - styles.css 1598 行，.item-error 和 .message-list 各定义两次 - 字号 10/11/12/13/14px 混用，圆角 3–12px 混用 - 响应式用 viewport media query，tool window 宽度变化时不一定准确

建议分三层改：

  • 先补 token：字号、间距、圆角、状态色，把散落的 px 收口。
  • 图标统一成 14–16px 线性图标，替换 emoji 和几何符号。
  • 响应式从 viewport media query 改成容器查询，tool window 多窄都成立。

方向确认后，我可以先出一版静态原型，再改 React 代码，避免反复返工。
